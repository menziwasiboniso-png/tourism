HOW TO OPEN
1. Extract the ZIP file.
2. Open the lesotho_tourism_website folder in Visual Studio Code.
3. Open index.html in a browser, or use the Live Server extension in Visual Studio Code.
4. Keep the folder structure unchanged so the CSS and JavaScript links continue to work.

FEATURES
- Six interconnected HTML pages
- HTML5 semantic structure
- External CSS stylesheet
- Bootstrap 5 navbar, responsive grid, cards, accordion, modal, alerts and forms
- Responsive layouts for mobile, tablet and desktop
- Destination filtering
- Image gallery preview with next and previous controls
- Destination detail modal
- Dark and light mode saved with localStorage
- Booking enquiry validation
- Registration validation with password confirmation
- Local profile name saved with localStorage

IMPORTANT
The website uses online images and the Bootstrap CDN, so an internet connection is needed for those assets.
The forms are front-end demonstrations only. They do not send bookings or registrations to a real business or database.
Replace demonstration images with your own properly licensed images if required by your lecturer.
